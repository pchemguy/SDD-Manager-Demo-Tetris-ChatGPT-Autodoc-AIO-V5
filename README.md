# Browser Tetris

A keyboard-first browser Tetris project in design preparation. Product code has not been implemented.

The [approved project brief](docs/dev/PROJECT.md), [architecture](docs/dev/ARCHITECTURE.md), [decomposition](docs/dev/DECOMPOSITION.md) and [specification](docs/dev/SPEC.md) define the complete target. [PLAN](docs/dev/PLAN.md) schedules five useful increments: classic play, modern piece handling, configurable play aids, penetrator gameplay and persistent configuration. [Layout](docs/dev/layout.md) allocates intended source/test paths; [TASKS](docs/dev/TASKS.md) contains planned executable work.

Document progress belongs to [DOCS_TASKS](docs/dev/DOCS_TASKS.md); control, decisions and evidence belong to [DOCS_PREPARATION](docs/dev/DOCS_PREPARATION.md). [HANDOFF](docs/dev/HANDOFF.md) identifies the current checkpoint. The separate SPEC/PLAN/TASKS review reports are document-level assessments; no game build or browser acceptance is claimed.

This project uses [SDD Manager](SDD-MANAGER.md). See [AI disclosure](AI_DISCLOSURE.md), [agent guidance](AGENTS.md), [browser policy](BROWSER_DEV_POLICY.md) and [Windows shell policy](WINDOWS_SHELL_POLICY.md). Setup/check commands will be documented after implementation validates them.
