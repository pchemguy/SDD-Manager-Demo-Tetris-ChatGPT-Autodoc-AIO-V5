# Browser Tetris

A browser-based Tetris project in design preparation. Product code has not been implemented.

The [project brief](docs/dev/PROJECT.md) proposes the complete target scope and gameplay interaction choices. [Preparation tasks](docs/dev/DOCS_TASKS.md) track document progress, and the [preparation record](docs/dev/DOCS_PREPARATION.md) retains current decisions and evidence.

This project uses [SDD Manager](SDD-MANAGER.md). See [AI disclosure](AI_DISCLOSURE.md) and [agent guidance](AGENTS.md). Browser testing follows [BROWSER_DEV_POLICY.md](BROWSER_DEV_POLICY.md); Windows execution follows [WINDOWS_SHELL_POLICY.md](WINDOWS_SHELL_POLICY.md).
